# Docs layout

[English](STRUCTURE.md) · [Русский](STRUCTURE.ru.md) · [Documentation](README.md)

How the pages are organized and where a new one goes.

## Structure

```
docs/
  README.md
  STRUCTURE.md
  assets/
  guides/
    getting-started/
    usage/
    auto-instrumentation/
    export/
    analysis/
    format/
    flight-recorder/
    runtime-counters/
    hosting/
    testing/
  concepts/
    flows/
  reference/
    api/
      index.md
      tracer.md
      scope-reader.md
    source-generator/
    session-options/
    opentelemetry/
    roslyn-analyzers/
  troubleshooting/
```

`README.md` is the table of contents. A page lives in `README.md` inside its own directory; a directory with several pages
has an `index.md` of its own. Every page has a Russian sibling with the `.ru.md` suffix, and the two link to each other on
the first line.

## Sections

| Directory            | Holds                                                                                              |
| -------------------- | -------------------------------------------------------------------------------------------------- |
| `guides/`          | Step-by-step scenarios: do X.                                                                      |
| `concepts/`        | The mental model and invariants: how it works inside.                                              |
| `reference/`       | Exact contracts: API, options, generator, diagnostics.                                             |
| `troubleshooting/` | Symptom, cause, fix.                                                                               |
| `assets/`          | Images referenced from the pages, regenerated by `samples/EmberTrace.DocScreenshots/capture.py`. |
